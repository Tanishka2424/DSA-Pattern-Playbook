# Day 1 – Number Basics

## Topics Covered
1. Palindrome Number
2. Prime Number
3. Armstrong Number

## Basic Concepts
- `while` loop – Repeats while a condition is true.
- `%` – Returns the remainder.
- `//` – Performs floor division.
- `**` – Calculates power.
- `break` – Stops the loop.
- `len(str(n))` – Counts the number of digits.

## Important Notes

### Palindrome
A number that reads the same forward and backward.

Example: 121 → 121

### Prime
A number divisible only by 1 and itself.

Example: 2, 3, 5, 7

Note: 1 is not prime. 2 is the only even prime number.

### Armstrong
A number equal to the sum of its digits raised to the power of the number of digits.

Example: 153 = 1³ + 5³ + 3³
